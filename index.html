Abstract

Mobile applications increasingly make security-relevant decisions on the client: what to display, what to request, and what the server will accept as true. Our work studies that delegation empirically. We build reproducible pipelines for recovering the protocol semantics of closed-source clients, annotate the validation assumptions those protocols rest on, and publish the corpora and tooling behind every claim so that results can be replicated, extended or contradicted by other groups.

01Research directions
01

Recovering message schemas from proprietary mobile clients

Commercial mobile clients ship without documentation, so their wire formats have to be reconstructed from binary and runtime artefacts. We build semi-automated recovery pipelines that combine bundle extraction, dynamic tracing and differential replay to produce machine-checkable schemas, and we release the intermediate corpora so that a finding can be reproduced rather than merely asserted.

  • binary analysis
  • protobuf
  • differential testing
02

Mapping which decisions the server still delegates to the client

Not all client-side state is cosmetic. We instrument message traces to classify each server-visible action as client-authoritative, server-authoritative or ambiguous, then quantify how much progression or economic value rests on every ambiguous case. The output is a per-title trust map that is comparable across implementations.

  • protocol semantics
  • threat modelling
  • measurement
03

A reproducible taxonomy of server-side validation failures

We maintain an annotated corpus of validation gaps — replay, concurrency, integer-domain and idempotency failures — built under a fixed, published annotation protocol. Every record ships with the trace fragment it was derived from, so the labels can be re-scored by anyone instead of being taken on trust. The point is that prevalence claims about a whole application class become testable instead of anecdotal.

  • dataset annotation
  • reproducibility
  • public protocol
04

Measuring what client hardening actually buys

Anti-tamper, integrity attestation and obfuscation are widely deployed and rarely measured. We run ablation studies on instrumented builds to estimate the marginal cost each technique imposes on a competent adversary against the marginal cost it imposes on legitimate users and maintainers.

  • ablation study
  • benchmarking
  • usable security

Responsible disclosure

Findings that touch a live service are reported privately to the vendor first, with a 90-day coordination window before any detail is published. No exploit code, no live accounts and no production data are ever included in our corpora; measurements are taken on instrumented builds or on data supplied under permission.

Status of this initiative

Thien Menh Research is an independent, self-funded research initiative. It is not an accredited university, degree-awarding body or registered laboratory, and it issues no credentials of any kind. Work published here is released as open preprints with tooling and data attached, so that it is evaluated on the artefacts rather than on an affiliation.
