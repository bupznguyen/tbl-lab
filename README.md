**Thien Menh Research** is an independent, self-funded empirical mobile security research initiative studying client-server trust boundaries in closed-source mobile software — including protocol schema recovery, validation-gap taxonomies, and reproducible measurement pipelines.

## Responsible Disclosure

Findings that touch a live service are reported privately to the vendor first with a 90-day coordination window before any detail is published. No exploit code, live accounts, or production data are included in published corpora; measurements are conducted on instrumented builds or authorized test fixtures.

## Status

Thien Menh Research is an independent, self-funded research initiative. It is not an accredited university, degree-awarding body, or registered laboratory, and it issues no credentials of any kind.
